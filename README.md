# Study Flow
A studies tracking project, made for tracking time spent, helping understand where the user lacks and keep consistency.

## About

### Problem
I am studying foreign languages, but i find it difficult to maintain consistency and track my progress over time.

### Solution
Create a platform where study sessions about either specific topics or broader subjects can be tracked.
